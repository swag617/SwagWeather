🌦️ SwagWeather
Forecast-driven weather and a slow-moving season cycle, published live on a cross-plugin event bus for the rest of the Swag617 ecosystem to react to.
Paper 1.21 Java 17+ Requires SwagAPI 5 Intensity Tiers
Core Features
🌦️
Weather System
5 intensity tiers (CLEAR → THUNDERSTORM) mapped onto real vanilla storm/thunder state, driven by a per-world forecast queue with configurable, weighted random transitions.
🍂
Season Cycle
An independent Spring → Summer → Fall → Winter cycle, timed in real seconds or in-game days, tracked separately per world on its own cadence from weather.
🔌
Cross-Plugin Event Bus
Publishes every change on SwagAPI's shared bus ("weather" / "season" channels) so SwagFarming and SwagFishing react with zero compile-time dependency.
🖥️
Admin Web Panel
A live dashboard through SwagAPI's shared web server — per-world intensity, season, and forecast, plus force controls and a full settings editor.
The Integration Surface
No Compile-Time Dependency Required
Other Plugins React in Real Time
Every weather or season change is published on SwagAPI's event bus. SwagFarming turns real rain into genuine crop growth-speed bonuses and season-match multipliers; SwagFishing turns a storm into a temporary Feeding Frenzy and announces seasonal migratory fish. A compile-time SwagWeatherAPI is also available for plugins that want it directly.

Admin & Permissions
🛠️
/sweather (5 subcommands)

🔐
1 Permission Node
swagweather.admin (default op) gates the entire /sweather command tree at the plugin.yml level.

Troubleshooting
Answers for a plugin that won't enable, weather that won't change, and seasons that don't seem to be advancing.
