# 🌦️ SwagWeather <small>v1.0.5</small>

> Forecast-driven weather and slow-moving season simulation for Minecraft: real vanilla weather, a 5-tier intensity model, and a cross-plugin event bus other Swag617 plugins react to in real time.

<span style="background:rgba(255,255,255,0.15);border:1px solid rgba(255,255,255,0.3);border-radius:20px;padding:4px 12px;font-size:13px;font-weight:600;margin-right:6px;">Paper 1.21</span><span style="background:rgba(255,255,255,0.15);border:1px solid rgba(255,255,255,0.3);border-radius:20px;padding:4px 12px;font-size:13px;font-weight:600;margin-right:6px;">Java 17+</span><span style="background:rgba(255,255,255,0.15);border:1px solid rgba(255,255,255,0.3);border-radius:20px;padding:4px 12px;font-size:13px;font-weight:600;">Requires SwagAPI</span>

- 🌦️ 5-tier weather intensity mapped onto real vanilla storm/thunder state
- 📅 A genuine forecast queue: see what's coming, and when
- 🍂 An independent Spring → Summer → Fall → Winter season cycle
- 🔌 Publishes on SwagAPI's event bus so SwagFarming and SwagFishing react without a compile-time dependency
- 🖥️ Admin web panel with live state, force controls, and a full settings editor
- 🛡️ Per-world isolated tick loops: one bad world can't stall the rest
